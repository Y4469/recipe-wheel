# משחק הבישול — שלוף את המתכון שלך

משחק HTML בעברית וב-RTL.

## איך משחקים
1. פותחים את `index.html`.
2. לוחצים "מתחילים".
3. כל שחקן שולף פתק אקראי עם מתכון.
4. מבשלים במשך 45 דקות.
5. מסמנים "סיימתי לבשל" ומקבלים 100 נקודות.
6. המטרה: להשלים את 12 המתכונים ולצבור עד 1200 נקודות.

## GitHub Pages
העלו את `index.html` ואת תיקיית `assets` לאותו Repository.
לאחר מכן הפעילו GitHub Pages מתוך Settings → Pages ובחרו את ה-branch הראשי ואת תיקיית `/root`.
